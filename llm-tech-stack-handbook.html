01语言模型从哪里来Origins & paradigm shifts基础＋

LLM 没有唯一公认的诞生年份。学习历史时，区分语言建模目标、预训练范式、大规模涌现能力和产品化浪潮：它们是相关但不同的演进线索。

知识结构 · 学什么，为什么

前史：统计与神经语言模型
N-gram 用有限历史估计下一个词；词向量与 RNN/LSTM 学习连续表示。理解稀疏性、长依赖和并行训练的限制即可，不必把旧模型全部重做一遍。
2017：Transformer
Attention 让序列位置之间直接交互，并使训练易于并行。原始 Transformer 是 encoder–decoder，不能把它与今天常见的 decoder-only 等同。
2018–2019：预训练迁移
ELMo、GPT、BERT、T5 分别提供不同的上下文表征、生成和去噪路线。比较 causal LM、masked LM 与 encoder–decoder 的信息可见范围。
2020–2022：规模与指令
GPT-3 推动 in-context learning；Scaling Laws 和 Chinchilla 讨论资源分配；指令微调、RLHF 与 CoT 改变模型的使用方式。
2023–2024：开放模型与高效系统
开放权重生态、参数高效微调、偏好优化、MoE、低精度与推理服务加速发展。模型质量与数据、训练和系统设计共同演进。
2025–2026：推理与可执行任务
推理 RL、推理时计算、混合架构、条件记忆、原生多模态和长程 Agent 成为重要研究分支。新分支叠加在旧基础之上，并不意味着旧技术整体被淘汰。

动手实践

画一张三路线对照表：模型目标、能力训练、计算系统；为每次变化写明“旧瓶颈—新机制—新代价”。

验收标准

  • 能解释 BERT 为什么不等价于聊天 LLM。
  • 能区分参数训练、上下文学习、外部检索和工具执行。
判断边界

时间轴表示代表性研究出现的阶段，不表示每种技术的首次发明，也不宣称列尽所有模型。

02概率目标、梯度与资源账本Objectives & resource accounting基础＋

真正进入技术栈的门槛，是能把一个训练或推理配置转换成概率目标、张量形状和资源账本。

pθ(x₁:T) = ∏ₜ pθ(xₜ | x<t)；L = −Σₜ log pθ(xₜ | x<t)

知识结构 · 学什么，为什么

自回归目标
理解联合概率分解、teacher forcing、交叉熵、label shift、padding mask 与 loss mask；区分 token 平均和样本平均。
优化与统计
掌握反向传播、AdamW、梯度裁剪、有效 batch、梯度累积、KL 散度与采样估计；RL 分支再补 policy gradient 和 importance sampling。
显存组成
分别计算权重、梯度、优化器状态、激活、KV Cache、通信缓冲区和临时 workspace。混合精度是否保留 FP32 master weights 取决于实现。
算力与带宽
Dense Transformer 训练中常用 C≈6ND 作粗估，N 为参数量、D 为训练 token 数；长上下文 attention、MoE、重计算和通信都会使这一估算不充分。
测量纪律
GPU 工作异步执行，计时需同步或使用 CUDA events；记录 warmup、稳定迭代、显存峰值和软件环境，避免把首次编译当稳态速度。

动手实践

给小模型训练写资源预测表，再用 profiler 和显存统计解释预测与实测的差距。

验收标准

  • 能写出 shifted next-token loss，并通过手工样例核对。
  • 能说明模型参数装得下，为什么训练仍会 OOM。
判断边界

困惑度只有在 tokenization、数据与评测协议可比时才适合直接比较。

03Tokenizer、序列与对话协议Tokenization & serialization基础＋

Tokenizer 是模型与真实文本之间的接口。词表、特殊 token、对话模板和截断策略都会影响质量、成本与兼容性。

知识结构 · 学什么，为什么

编码方法
理解字符、字节、BPE、Unigram 和 SentencePiece；比较词表大小、压缩率、多语言覆盖与未登录输入。
训练与复用
训练 tokenizer 需要独立语料和固定预处理。加载已有模型时，必须匹配对应 tokenizer、特殊 token 与配置。
序列构造
掌握 BOS/EOS、padding 方向、position IDs、长文切块和 packing。独立样本的边界、attention 可见性与 loss 统计需明确。
聊天与工具协议
system/user/assistant/tool 的结构如何序列化？generation prompt、工具返回、思考片段和多模态占位符怎样进入模型？模板错位可造成静默退化。
效率与误差
中文、数字、代码的 token 长度分布不同；“同样字数”的输入并不意味着同样计算成本。

动手实践

实现简化 BPE；比较中英文、代码、数学样本的 token 长度，检查对话模板与 label mask。

验收标准

  • 能往返编码解码正常文本和特殊字符。
  • 能打印一条训练样本，逐位置解释哪些 token 参与 loss。
判断边界

不要根据字符数直接推算上下文占用，也不要给已有权重随意替换 tokenizer。

04从零实现现代 TransformerDecoder-only foundations基础＋

以一个可读的小模型为主线，掌握每层的张量流，再理解现代 LLM 的常见改动。

Attention(Q,K,V) = softmax(QKᵀ / √dₖ + mask)V

知识结构 · 学什么，为什么

Attention
Q/K/V 投影、分头、缩放点积、causal mask、Softmax 和输出投影；理解训练中的并行矩阵计算与生成中的逐 token 执行。
位置与归一化
比较绝对位置编码与 RoPE、LayerNorm 与 RMSNorm、PreNorm 与 PostNorm；理解归一化和残差对优化稳定性的影响。
FFN 与门控
理解 GELU、SwiGLU、扩展维度和参数分配；别把 FFN 当成 attention 后的无关附件，它常占很大参数与计算比例。
训练到生成
实现权重初始化、可选权重绑定、dropout、checkpoint、采样和缓存；逐步核对 full forward 与 incremental forward。
数值正确性
对照一个可信实现检查输出和梯度；用小数据过拟合、固定随机种子和不同 dtype 测试定位问题。

动手实践

从零实现小型 Decoder-only LM，训练到明显优于随机基线，并实现有缓存和无缓存两条生成路径。

验收标准

  • 能逐层写出 tensor shape 与参数量。
  • 缓存与无缓存在相同前缀下的 logits 在合理数值误差内一致。
判断边界

“能生成中文”不是训练正确性的充分证据；loss、数值核对和数据边界同样重要。

05Attention、位置与稀疏化MHA → GQA / MLA / sparse attention进阶＋

区分四个不同问题：表示能力、KV 存储、长序列计算量和算子执行效率。不同 attention 技术往往只解决其中一部分。

知识结构 · 学什么，为什么

MHA / MQA / GQA
从每个 query head 独立使用 KV，到多个 query heads 共享 KV，比较缓存容量、内存带宽与质量。
MLA
学习 KV 的潜变量压缩、解压或权重吸收，以及位置编码与内容表示的处理方式；其缓存模型不能直接套用普通 GQA 公式。
位置外推
学习 RoPE 频率、位置插值与 YaRN 等扩展策略；分清“能接收更长输入”和“远距离信息使用有效”。
稀疏注意力
滑动窗口、块稀疏、全局 token、内容选择与可学习 indexer：分析哪些连接被保留，选择本身花费多少计算。
算法与 kernel
FlashAttention 优化精确 attention 的执行；DSA 等方法选择部分上下文。两者可协同，但不是同一种近似机制。

动手实践

在同一小模型或可控输入上比较 GQA 的缓存开销；对一个稀疏选择模块测选择耗时与 attention 耗时。

验收标准

  • 能区分减少 KV heads、压缩 KV、稀疏连接与 IO 优化。
  • 能解释短序列下稀疏 attention 为什么可能不划算。
判断边界

减少 attention 计算量并不保证端到端提速，indexer、TopK 和不规则访存可能成为新瓶颈。

06MoE 与条件计算Sparse activation & expert systems进阶＋

MoE 的核心是按输入选择部分专家计算，使总容量与单 token 激活计算量部分解耦，同时引入路由和分布式通信问题。

知识结构 · 学什么，为什么

路由与专家
掌握 router logits、Top-k、专家 FFN、shared experts、细粒度专家以及输出加权；分别统计总参数与激活参数。
负载均衡
理解路由塌缩、capacity、token dropping、辅助损失和无辅助损失的平衡方法；检查不同专家的真实负载分布。
训练稳定性
路由精度、专家初始化、梯度与通信顺序影响稳定性；平均负载均衡不代表每个 microbatch 都均衡。
Expert Parallelism
token dispatch/combine、All-to-All、跨节点带宽、计算通信重叠与专家复制；硬件拓扑决定有效吞吐。
推理代价
低 batch、长尾专家、权重搬运和热点变化会削弱稀疏计算优势。总权重仍需被存储、分片或按需搬运。

动手实践

实现 Top-2 小型 MoE，记录专家 token 分布；比较不同平衡设置下的质量、负载与耗时。

验收标准

  • 能解释总参数大但激活少为何不等于低显存。
  • 能把 router、dispatch、专家计算和 combine 分别测量。
判断边界

比较 dense 与 MoE 要说明是否等 FLOPs、等总参数、等激活参数或等训练预算。

07SSM、线性注意力与混合架构Finite-state sequence models进阶＋

全注意力保存显式历史，状态空间或线性递归机制把历史压缩进状态。研究价值来自质量、状态容量、长序列成本之间的权衡。

知识结构 · 学什么，为什么

线性注意力
理解 kernel feature map、累积状态，以及为什么不能简单把 softmax attention 原样变成线性复杂度。
SSM 与 Mamba
掌握状态更新、选择性机制、并行 scan 与逐步推理；区分序列长度方向的复杂度和真实硬件效率。
Delta rule 与门控
理解状态写入、遗忘、纠错和容量限制；Gated DeltaNet、KDA 为进阶案例。
混合层设计
交替使用递归层和全局 attention 层以保留显式检索能力；混合比例、层位置与任务分布都需要实证。
2026 架构扩展
条件记忆、残差聚合和稀疏 indexer 可与混合架构组合；需要分别消融，不能只报告最终大模型分数。

动手实践

实现一个简化线性递归模块，在复制、关联检索和长度外推任务上与 attention 比较。

验收标准

  • 能说明固定状态如何限制精确历史检索。
  • 能分别测 prefill、decode、状态大小和质量。
判断边界

“线性复杂度”不是对所有序列长度、硬件和任务都更优的结论。

让 KV Cache 的显存可计算

THEORETICAL KV MEMORY1.00 GiB

2 × 32 × 1 × 8192 × 8 × 128 × 2 bytes

假设：所有层、所有序列的缓存结构与长度相同，无共享、无分片、无淘汰。计算不含权重、激活、分页碎片、量化 scale、通信缓冲区和临时 workspace；4-bit 是理想数据位宽。MLA、跨层共享、递归状态和混合架构需另建模型。T 包含当前已经缓存的输入与生成 token。

试一试：只把 KV heads 从 8 改成 32，理论缓存变为 4 倍；把并发序列数从 1 改成 8，再观察显存。由此思考 GQA、prefix sharing、分页与调度各自解决的是什么。

多模态文档 / 图表分析

09 / KEEP TERMS PRECISE

术语速查

Pretraining
预训练：从大规模数据学习通用表示与生成分布。
SFT
监督微调：用示例训练特定任务或指令行为。
RLHF / RLAIF
基于人类 / AI 反馈的学习框架；并非某一个固定优化器。
RLVR
基于可验证奖励的强化学习，例如测试或数学答案验证。
MoE / EP
混合专家 / 专家并行；区分条件计算与分布式放置。
GQA / MLA
共享 KV heads / KV 潜变量压缩；两者的缓存结构不同。
Prefill / Decode
处理输入序列 / 增量生成输出 token。
TTFT / TPOT / ITL
首 token 时间 / 平均输出 token 时间 / 相邻 token 间隔；报告测量定义。
SLO / Goodput
服务目标 / 满足既定目标的有效吞吐。
PTQ / QAT
训练后量化 / 量化感知训练。
DP / TP / PP / CP
数据 / 张量 / 流水线 / 上下文并行；具体定义以实现为准。
RAG / Agent / Harness
检索增强生成 / 行动反馈系统 / 管理工具与执行的运行框架。
